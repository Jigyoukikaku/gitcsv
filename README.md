# Git CSV ビューワー

別の非公開リポジトリにあるCSV・WORKBOOK.jsonを、スプレッドシート風の画面で表示・編集する静的アプリです。このリポジトリは画面の配信専用です。

## 所有者による初回設定

1. このリポジトリの **Settings → Pages** を開きます。
2. **Source** は **Deploy from a branch**（ブランチから配信）を選びます。
3. **Branch** は **main**、フォルダは **/ (root)** を選び、**Save** を押します。
4. 公開処理が終わると `https://jigyoukikaku.github.io/gitcsv/` が利用できます。

非公開リポジトリからのPages配信には対応する有料プランが必要です。Pagesを設定できない場合は所有者がプランを確認してください。無料プランで運用するためにこの画面専用リポジトリを公開する場合も、所有者の判断で実施してください。案件データ側のリポジトリは公開しません。

非公開リポジトリであっても、Pagesのサイトまで非公開になるとは限りません。この画面とこのREADMEは一般公開される前提で管理してください。

## 利用方法

画面を開き、データ側のリポジトリ・ブランチ・保存フォルダ・利用可能な読み取り専用トークンを入力します。画面のURL末尾に `#repo=OWNER%2FREPOSITORY&branch=main&path=gitcsv&book=book1` を付けると、トークン以外の接続先を事前入力できます。URLにトークンを入れないでください。

- 画面だけをこのリポジトリから配信します。CSVは利用者のブラウザからGitHub APIへ直接アクセスして読み込みます。
- 人の編集はブラウザ内で行い、保存したブックZIPをデータ側リポジトリへアップロードします。AIもデータ側のCSVとWORKBOOK.jsonを編集します。
- データ側にはGit CSV対応の設定・ブック・ZIP取込Actionsが別途必要です。このリポジトリを置くだけで任意のCSVリポジトリに取込処理が追加されるわけではありません。
- トークンを永続保存しません。端末の下書き・ダウンロードZIPにはデータが含まれるため、利用者の情報管理ルールに従ってください。
- Fine-grained tokenは誰でも任意の所有者向けに作成できるわけではありません。別の個人が所有する非公開リポジトリへの共同作業者アクセスには制限があります。所有者の個人トークンをチームの共通キーとして配らないでください。

## 入れてよいファイル

`index.html`、`assets/`内の画面用JS・CSS、`.nojekyll`、配信専用の説明ファイルだけです。CSV、WORKBOOK.json、ブックZIP、顧客資料、認証トークンを追加しないでください。

## 更新

画面の更新時は、検証済みの静的ビルドからHTML・JS・CSSだけを反映します。現在のJS/CSSは配信済みビルドであり、開発ソース一式ではありません。データ側リポジトリの内容をこのリポジトリへコピーしないでください。mainを更新するとPagesが再配信します。
